# Daskalova Display and Daskalova Text

Modified versions of [Newsreader](https://github.com/productiontype/Newsreader) by Production Type,
used under the SIL Open Font License 1.1 (see `OFL.txt`).

Changes from Newsreader:

- **Daskalova Display**: Newsreader at optical size 72, weight 370, with a redrawn lowercase `y`
  whose tail sweeps left under the previous letter and curls up.
- **Daskalova Text** (Regular, Italic, SemiBold): Newsreader at optical size 16, unchanged outlines.
- All styles renamed and subset to Latin characters for the web.
